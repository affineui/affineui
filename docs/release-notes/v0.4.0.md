v0.4.0 focuses on performance, correctness, and documentation improvements across the library.

### Highlights
- Eliminated multi-second drag lag on macOS by draining the NSEvent queue per pulse. (#4)
- Gallery now defaults to Decius and resolves framework assets deterministically. (#5)
- DevTools hotkey and launcher now work end-to-end. (#3)

### Bug fixes
- Fixed resize-to-blank to use recollect on media crossing instead of set_html. (#6)
- Fixed framework asset resolution to be deterministic. (#5)

### Changes
- Rewrote READMEs with clearer identity, per-language installation instructions, and verified examples. (#10)
- Added image captions, language picker, and translated READMEs into 11 additional languages. (#14)
- Clarified optimized code size and implementation language in README. (#13, #11, #12)
- Refactored DOM resolver and recollect logic into a local lambda for better code organization. (#8)
- Implemented tag-driven release pipeline for cargo, nuget, PyPI, and GitHub Releases. (#7)
- Updated CI with two-step dispatch release UX for drafting AI notes and cutting tags. (#9)
- Integrated modularized-document refactor and fixed amalgamation in the build system. (#2)
- Updated release-notes CI to use COPILOT_PAT for Copilot CLI authentication. (#15)
