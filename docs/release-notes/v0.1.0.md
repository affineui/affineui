AffineUI is a native UI library implementing a fast, accurate web standards renderer, CSS engine, and layout system. This first stable release includes Python, Rust, and C# bindings; a cross-platform windowing system; and comprehensive component implementations with browser-accurate rendering.

### Highlights
- Python bindings via pybind11, with Rust and C# wrappers on the C ABI. (#20)
- Profiling and development tooling with affinetools, telemetry, and symprof. (#19)
- Skeuomorphic hardware widget kit with Affine 2600 synth sample. (#22)
- View reconciler and interaction performance improvements. (#23)
- Cross-platform windowing: D3D11 on Windows, Metal on macOS, GL 4.1 on Linux. (#49)
- Complete CSS table model (display:table) with aligned columns. (#70)
- Text rendering with browser-exact vertical metrics and justified alignment. (#67)
- Menu system with VS Code hit model, hover-follow, and submenu cascades. (#42)
- Docking/tearoff UI system with framework-backed command panels. (#85)
- CSS custom properties (var()) and calc() length arithmetic. (#59)
- Conformance testing infrastructure with visual A/B harness. (#82)
- Host-owned GPU embedding API with efficient update/dirty/sub-rect rendering. (#50)
